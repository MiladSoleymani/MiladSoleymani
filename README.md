### About

- 🔬 **Current research** — how reinforcement learning shapes language choice in LLMs: compliance patterns across multilingual reasoning tasks and code-switching dynamics.
- 🛠️ **Day job** — AI Engineer at QubitOrbit. Previously fine-tuned LLMs with RL and shipped RAG pipelines for healthcare at MyFast Medical; before that, computer vision at ATHLX and generative pipelines (diffusion, VAE, ControlNet) at RUTILEA.
- 🎓 **Teaching** — I teach Natural Language Processing at Islamic Azad University.
- 📍 Tehran, Iran · open to research collaborations in LLM alignment and biosignal learning.

### Selected work

**LLMs, RL &amp; NLP**

| Project | What it does | Stack |
|---|---|---|
| [**GRPO-EMPATHY**](https://github.com/MiladSoleymani/GRPO-EMPATHY) | Trains empathetic dialogue models with Group Relative Policy Optimization, using a semantic-similarity reward plus a fine-tuned RoBERTa empathy reward. | PyTorch, TRL, HuggingFace |
| [**Hybrid Bio+Clinical BERT with CNN**](https://github.com/MiladSoleymani/Hybrid-BioClinical-BERT-with-CNN) | Drug-review sentiment analysis benchmarking five models; the proposed hybrid pairs domain-specific BERT embeddings with CNN feature extraction. | PyTorch, Transformers |
| [**BBN Annotation Tool**](https://github.com/MiladSoleymani/BBN-Annotation) | Annotation and analysis tool for Breaking Bad News clinical conversations, built on the Appraisal Framework for Clinical Empathy. | Streamlit, Python |
| [**PDF QA using LLM**](https://github.com/MiladSoleymani/PDF-QA-using-LLM) | Retrieval-augmented question answering over PDF documents. | LangChain, Python |

**Biosignals &amp; medical AI**

| Project | What it does | Stack |
|---|---|---|
| [**EEG-CLIP**](https://github.com/MiladSoleymani/EEG-Clip) | CLIP-style contrastive learning for EEG motor-imagery classification — fixed-template and batch-wise variants over an ATCNet encoder, with subject-wise k-fold and t-SNE analysis. | PyTorch |
| [**Self-supervised Task-agnostic EEG Embedding**](https://github.com/MiladSoleymani/Self-supervised-Task-agnostic-EEG-Embedding) | Label-free EEG representations that transfer across downstream tasks, evaluated on BCI Competition IV-2a, LEE and CHB-MIT. | PyTorch Lightning |
| [**Infant Cry Classification**](https://github.com/MiladSoleymani/infant_cry_classification) | Five-class infant cry classification from audio (DonateACry corpus) with CNNs over spectrogram features. | PyTorch, librosa |
